## 代码质量亮点

### Context Canceled 修复

`cancelTurn` 和 `failTurn` 中的 context isolation 设计堪称典范：

```go
// Phase 1: 关键状态更新（10s 独立超时）
statusCtx, statusCancel := context.WithTimeout(context.WithoutCancel(ctx), 10*time.Second)
defer statusCancel()
if err := h.deps.TurnRepo.UpdateStatus(statusCtx, ...); err != nil { ... }

// Phase 2: 后续清理操作（10s 独立超时，不复用 Phase 1 的时间预算）
cleanupCtx, cleanupCancel := context.WithTimeout(context.WithoutCancel(ctx), 10*time.Second)
defer cleanupCancel()
```

注释清晰解释了为什么不能 `ctx = statusCtx`（时间预算共享问题），以及为什么需要 `context.WithoutCancel`（caller context 可能已取消）。
