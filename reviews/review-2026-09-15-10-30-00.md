## 行为等价性验证

### autoFillCompletedAt 边界情况

| 场景 | 预期行为 | 测试覆盖 |
|------|----------|----------|
| fields 无 status 键 | 不修改 completed_at | TestGoalRepo_Update_NonTerminalStatus_NoAutoCompletedAt |
| status 为非终态 (active) | 不修改 completed_at | TestGoalRepo_Update_ActiveStatus_NoAutoCompletedAt |
| status 为终态 + completed_at 为 nil | 自动填充 time.Now() | TestGoalRepo_Update_TerminalStatus_AutoCompletedAt |
| status 为终态 + completed_at 已设置 | 保留原值 | TestGoalRepo_Update_TerminalStatus_ExplicitCompletedAt |
| 所有终态 (completed/cancelled/exhausted) | 均触发自动填充 | TestGoalRepo_Update_CancelledStatus_AutoCompletedAt, ExhaustedStatus_AutoCompletedAt |

### SQLite 兼容性

- `time.Now()` 替代 `NOW()`：正确。SQLite 不支持 SQL 函数 `NOW()`，GORM 将 `time.Now()` 作为参数化查询值传入，行为等价。
- `FindExpiredLoops` 使用 `time.Now()` 作为查询参数：正确。测试中设置 `expires_at` 为过去时间即可触发匹配。

### 接口设计

- `autoFillCompletedAt(fields map[string]any, terminalStatuses []string)`: 参数设计合理。`fields` 使用 `map[string]any` 与 GORM Updates 保持一致；`terminalStatuses` 作为参数传入而非硬编码，使得函数可被 Goal 和 Loop 复用。
- `setupTestDBWithModels(t *testing.T, prefix string, models ...interface{}) *gorm.DB`: 签名清晰，`prefix` 用于隔离并行测试，`models...` 可变参数支持任意模型组合。
