### 2. 锁续期容错机制

```go
// Worker 和 SessionTurnManager 共享一致的容错逻辑
```

### 3. 双重 Cancel 安全网

```go
// 第一次检查：订阅前
if work.Status == StatusCancelled {
    cancelCh <- CancelMessage{...}
    adminCancelled.Store(true)
}

// 订阅 cancel 通知
cancelSub := w.q.SubscribeCancel(workCtx, claim.SessionID)

// 第二次检查：订阅后（覆盖竞态窗口）
if !adminCancelled.Load() {
    recheck, _ := w.q.LoadWork(workCtx, claim.WorkID)
    if recheck.Status == StatusCancelled {
        cancelCh <- CancelMessage{...}
    }
}
```
