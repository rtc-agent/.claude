**中等问题**:

`pkg/centrifuge-plus/logger.go:8-12` - `init()` 全局副作用

```go
func init() {
    log.SetOutput(os.Stderr)
}
```

**影响**: 会改变所有使用标准 `log` 包的组件的输出目标。当前项目主要使用 zap，实际影响有限，但违反了 package 应最小化全局影响的原则。

**建议**: 改为使用专用 `log.Logger` 实例：
```go
var defaultLog = log.New(os.Stderr, "", log.LstdFlags)

type defaultLogger struct{}

func (defaultLogger) Info(msg string, args ...any) {
    defaultLog.Printf("info: "+msg, args...)
}
// ... 其他方法
```
