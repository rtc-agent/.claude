## 未修复的已知模式（非本次审查范围）

以下为已知但不主动修复的模式（符合规范中"已有代码中的 any — 不主动清理"的原则）：

1. **s3-client.ts:253** `response.Body as any` — AWS SDK Body 类型为联合类型，需要 `as any` 检查 asyncIterator。这是 AWS SDK 类型限制，修改可能引入破坏性变更。
2. **entity-repository.ts** 多处 `as unknown as Record<string, unknown>` — 用于通用 UIUpdateBus 序列化的实体转换，属于合理的泛型序列化模式。
3. **zod-to-openapi.ts** 多处 `as any` — 访问 Zod 内部 _def 属性，属于第三方库内部 API 访问，类型定义不完整。
4. **debug-api-ext.ts** 多处 `as unknown as` — 用于构造 OfflineWebSocket mock，属于测试/调试基础设施。
