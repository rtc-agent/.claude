# 会话管理

## 概述

会话是用户与 AI 对话的容器。用户可创建、切换、重命名、删除会话，也可基于某条消息分叉创建新会话。

## 会话状态

```mermaid
stateDiagram-v2
    [*] --> Idle: 创建会话
    Idle --> Active: 发送消息 / 恢复 Turn
    Active --> Idle: Turn 完成 / 中断 / 失败
    Idle --> Closed: 关闭会话
    Active --> Closed: 关闭会话
    Closed --> [*]
```

| 状态 | 含义 |
|------|------|
| Idle | 空闲，可发送新消息 |
| Active | 正在执行 Turn（AI 处理中） |
| Closed | 已关闭，不可再写入 |

## 会话操作

```mermaid
flowchart TD
    A[会话操作] --> B[创建]
    A --> C[列表]
    A --> D[切换]
    A --> E[重命名]
    A --> F[分叉]
    A --> G[关闭]

    B --> B1[发送消息时自动创建<br/>或点击新建按钮]
    C --> C1[游标分页<br/>按创建时间倒序]
    D --> D1[切换后加载对应消息]
    E --> E1[修改会话标题]
    F --> F1[基于某条消息<br/>复制历史创建新会话]
    G --> G1[标记为 closed<br/>停止正在执行的 Turn]
```

| 操作 | 说明 |
|------|------|
| 创建 | 发送消息时自动创建；也可点击新建按钮创建空会话 |
| 列表 | 按创建时间倒序，游标分页加载 |
| 切换 | 选择历史会话，加载对应消息 |
| 重命名 | 修改会话标题 |
| 分叉 | 基于某条消息复制历史，替换该消息内容，触发新的 AI 流程 |
| 关闭 | 标记为 closed，停止正在执行的 Turn |

## 会话标题

```mermaid
flowchart TD
    A[标题来源] --> B[自动截取]
    A --> C[手动重命名]
    A --> D[分叉继承]

    B --> B1[发送消息创建会话时<br/>取消息前 50 字符]
    C --> C1[用户主动修改标题]
    D --> D1[新会话继承旧会话标题]
```

## 会话分叉

```mermaid
flowchart LR
    A[选择一条消息] --> B[点击分叉]
    B --> C[复制该消息之前的历史]
    C --> D[替换该消息为新内容]
    D --> E[创建新会话]
    E --> F[触发 AI 处理]
```

分叉用于：对之前的回答不满意，修改问题重新生成。

## 并发约束

| 约束 | 说明 |
|------|------|
| 单 Turn 执行 | 同一会话同时只能有一个 Turn 在执行 |
| 归属隔离 | 用户只能操作自己的会话 |
| 关闭即冻结 | 已关闭的会话不可再发送消息 |

## 本地优先

```mermaid
flowchart LR
    A[用户操作] --> B[写入 IndexedDB]
    B --> C[立即返回]
    B --> D[后台同步到服务端]
    D --> E{成功?}
    E -->|是| F[标记 synced]
    E -->|否| G[标记 failed<br/>支持重试]
```

会话数据先存本地，后台异步同步，保证离线可用。

## 实时更新

服务端通过 WebSocket 推送会话变更（创建、更新、关闭），前端自动同步到本地存储并更新 UI。
