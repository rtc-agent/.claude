# SVG 规范

> _图标是产品的微表情。每一个像素都应当清晰、一致、可控。_

---

## 1. 图标来源

### 统一使用 @primer/octicons

所有图标从 `@primer/octicons`（已在 `package.json` 中）获取。不从其他图标库混用。

### 尺寸与命名

- **尺寸**：16x16 像素
- **命名**：`{name}-16.svg`，如 `send-16.svg`、`gear-16.svg`
- **存放**：`packages/component/src/icons/svg/`

### 新增图标流程

1. 从 [octicons](https://primer.style/foundations/icons) 选择合适图标
2. 下载 SVG，清洗后放入 `svg/` 目录
3. 在 `icons.ts` 中注册
4. 导出命名模板供组件使用

---

## 2. 导入方式

### Vite `?raw` 导入

SVG 文件通过 Vite 的 `?raw` 后缀导入为字符串，再转为 Lit 模板。

```typescript
// icons.ts
import { html } from 'lit'
import { unsafeHTML } from 'lit/directives/unsafe-html.js'

import sendSvg from './svg/send-16.svg?raw'
import gearSvg from './svg/gear-16.svg?raw'

function toLitTemplate(svgString: string) {
  return html`${unsafeHTML(svgString)}`
}

export const sendIcon = toLitTemplate(sendSvg)
export const gearIcon = toLitTemplate(gearSvg)

// 图标注册表
export const icons = { send: sendIcon, gear: gearIcon } as const
export type IconName = keyof typeof icons

export function getIcon(name: IconName) {
  return icons[name]
}
```

### 组件使用

```typescript
import { sendIcon, gearIcon } from '../../icons/index.js'

render() {
  return html`
    <button class="send-btn">${sendIcon}</button>
    <button class="settings-btn">${gearIcon}</button>
  `
}
```

### 禁止

- 禁止使用 `<img src="...">` 引用 SVG 文件（无法用 CSS 控制内部样式）
- 禁止使用 `fetch` 动态加载 SVG（增加网络请求，无必要）

## 3. SVG 清洗

### 新增 SVG 前必须清洗

从 octicons 或其他来源获取的 SVG 必须清洗后才能使用。

### 清洗规则

| 操作 | 原因 |
|------|------|
| 移除 `width` / `height` 属性 | 由 CSS 控制尺寸 |
| 移除 `fill` 属性 | 由 CSS `currentColor` 控制颜色 |
| 移除 `xmlns:xlink` 等冗余命名空间 | 减少体积 |
| 移除 `<title>`、`<desc>`、`<!-- comments -->` | 无用的 metadata |
| 移除编辑器数据（`inkscape:*`、`sodipodi:*`） | 无用的编辑器元数据 |
| 合并同属性路径 | 减少 DOM 节点 |

### 建议引入 svgo

在构建流程中加入 `svgo` 自动清洗：

```bash
# 安装
pnpm add -D svgo

# 清洗单个文件
npx svgo src/icons/svg/new-icon.svg

# 批量清洗
npx svgo src/icons/svg/*.svg
```

### 清洗前后对比

```xml
<!-- ❌ 清洗前（~1.2KB） -->
<?xml version="1.0" encoding="UTF-8"?>
<svg xmlns="http://www.w3.org/2000/svg" width="16" height="16" viewBox="0 0 16 16">
  <!-- Generated by Inkscape -->
  <title>send icon</title>
  <path fill="#333333" d="M2.7 1.2L14.5 7.4c.5.3.5 1 0 1.2L2.7 14.8c-.6.3-1.2-.1-1.2-.8V2c0-.7.6-1.1 1.2-.8z"/>
</svg>

<!-- ✅ 清洗后（~200B） -->
<svg viewBox="0 0 16 16" xmlns="http://www.w3.org/2000/svg">
  <path d="M2.7 1.2L14.5 7.4c.5.3.5 1 0 1.2L2.7 14.8c-.6.3-1.2-.1-1.2-.8V2c0-.7.6-1.1 1.2-.8z"/>
</svg>
```

## 4. 样式约束

### 图标用 `fill: currentColor`

所有功能图标必须继承父元素的文字颜色。

```css
/* ✅ 继承父元素颜色 */
.send-btn svg,
.settings-btn svg {
  fill: currentColor;
}

/* 按钮 hover 时图标自动跟随 */
.send-btn:hover {
  color: var(--rtc-color-primary);
}

/* ❌ 硬编码颜色 */
.send-btn svg {
  fill: #007acc;
}
```

### 品牌/装饰图形用 CSS 变量

```css
/* ✅ 使用主题变量 */
.logo svg {
  fill: var(--rtc-color-primary);
  opacity: 0.7;
}

/* ❌ 硬编码 */
.logo svg {
  fill: #007acc;
}
```

### SVG 内部不写颜色

清洗后的 SVG 文件中不应有 `fill` 属性，颜色完全由外部 CSS 控制。

## 5. 尺寸控制

### 通过 CSS 设置宽高

不依赖 SVG 自身的 `width`/`height` 属性。

```css
/* ✅ CSS 控制尺寸 */
.window-btn svg {
  width: 14px;
  height: 14px;
}

.icon-btn svg {
  width: 16px;
  height: 16px;
}

.logo svg {
  width: 72px;
  height: 72px;
}
```

### 统一尺寸档位

| 档位 | 尺寸 | 用途 |
|------|------|------|
| **sm** | 14px | 窗口控件（最小化、最大化） |
| **md** | 16px | 按钮图标、操作图标（默认） |
| **lg** | 64-72px | 装饰图形、Logo |

新增图标尺寸必须落入已有档位，不随意定义新尺寸。

---

## 6. 装饰图形

### 使用 Lit `svg` tagged template

一次性装饰图形（如 Logo、空状态插图）使用内联 `svg` 模板，不走文件导入。

```typescript
import { svg } from 'lit'

const emptyStateLogo = svg`
  <svg viewBox="0 0 64 64" xmlns="http://www.w3.org/2000/svg">
    <path d="M32 8 L32 12 L28 12 ..."/>
  </svg>
`

render() {
  return html`<div class="logo-container">${emptyStateLogo}</div>`
}
```

### 适用场景

- Logo / 品牌标识
- 空状态插图
- 加载动画图形

### 不适用场景

- 功能图标 → 走 `icons.ts` 注册流程
- 重复使用的图形 → 提取为 icon

---

## 7. 禁止项

| 禁止 | 原因 |
|------|------|
| **icon font** | 无法精细控制每个图标，加载整个字体浪费带宽 |
| **SVG sprite sheet** | 增加复杂度，`<use>` 引用在 Shadow DOM 中有兼容问题 |
| **SVG 内硬编码颜色** | 破坏主题适配，无法响应 light/dark 切换 |
| **外部 SVG 文件引用（`<img>` / `<object>`）** | CSS 无法穿透控制内部元素 |
| **运行时动态 fetch SVG** | 增加不必要的网络请求 |

---

## 总结

SVG 是产品视觉的像素级表达。统一的来源、清洗流程、样式约束，让每个图标都像是同一个设计师的手笔。

> _"图标不是附属品。它和用户看到的每一个文字一样重要。"_
